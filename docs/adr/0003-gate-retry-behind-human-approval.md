# 将升级任务重试置于人工批准之后

第一版只允许 Agent 提议并执行单个升级任务的重试，且执行前必须由运维工程师完成明确的人工批准；批量重试、暂停批次、修改任务状态和停止调度不在第一版范围内。这样保留可演示的闭环处置能力，同时把模型建议与实际写操作隔离，降低误操作影响面。

## Considered Options

- Agent 自动执行重试
- 第一版只读，不执行任何写操作
- 单任务重试必须人工批准（选择）

## Consequences

- 系统必须区分“重试计划”和“重试执行”。
- 批准前只能读取数据、生成计划和预览影响范围。
- 执行接口必须接受受限的任务 ID，而不是任意模型生成的命令或状态变更。
