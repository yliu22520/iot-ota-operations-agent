# 使用受约束的诊断工作流

Agent 采用“识别对象、收集证据、验证假设、生成报告、审批处置、执行验证”的阶段流程；模型只能在当前阶段选择允许的工具，不能任意跳过证据收集、绕过人工批准或无限循环调用工具。这样保留 Agent 的动态工具选择能力，同时让安全边界、状态恢复和评测目标保持可控。

## Considered Options

- 让模型在所有工具之间自由循环
- 使用受约束的诊断阶段流程（选择）

## Consequences

- 每个阶段需要定义输入、允许工具、完成条件和失败出口。
- 工作流状态必须持久化，便于中断后恢复和审计。
- 后续增加工具时需要明确它属于哪个阶段，而不是直接暴露给 Agent。
