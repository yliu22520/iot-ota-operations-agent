# 将审计记录作为追加式业务事实保存

系统以追加方式保存诊断、工具调用摘要、证据来源、重试计划、批准和执行结果等审计记录，不把普通应用日志作为唯一依据。这样可以还原 Agent 的建议、人工决定与实际写操作之间的关系，并支持问题排查、演示和评测。

## Considered Options

- 只保留应用日志
- 将关键过程保存为追加式审计记录（选择）

## Consequences

- 审计记录不能被后续状态更新静默覆盖。
- 需要区分面向调试的日志与面向业务追责的审计事实。
- 第一版仍可使用同一个数据库，但审计表的写入边界必须独立。
- 在线演示可以在 24 小时后整体销毁并重建临时数据集，但在数据集存活期间不得更新或删除其中的单条审计事实。
