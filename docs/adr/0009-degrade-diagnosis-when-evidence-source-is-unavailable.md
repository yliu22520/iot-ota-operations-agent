# 数据源不可用时允许带证据缺口完成诊断

当日志或其他证据工具超时、不可用或返回失败时，诊断任务可以带着已有证据继续，但必须标记缺失来源并区分“证据不完整”和“证据不足”。部分证据足以支持明确规则结论时可以生成报告；任何证据缺口都不能被模型静默补全，也不能单独支撑重试执行。

## Considered Options

- 任一工具失败就终止整个诊断
- 忽略工具失败并让模型继续推断
- 显式披露缺口并按证据充分性决定后续动作（选择）

## Consequences

- 工具失败必须成为诊断任务中的可审计事件。
- 报告需要展示缺失的证据来源。
- 重试资格判断必须依赖明确的结构化条件，而不是模型对不完整上下文的自信程度。
