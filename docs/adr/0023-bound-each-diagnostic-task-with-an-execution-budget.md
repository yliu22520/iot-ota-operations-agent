# 为每个诊断任务设置执行预算

每个诊断任务默认最多调用 10 次工具、进行 8 轮模型交互，单个只读工具最多自动重试 1 次，单次模型输出最多 4K Token，单次组装上下文最多 32K Token，并设置 90 秒总超时；这些数值作为可配置的初始上限。预算耗尽后任务停止继续推理，保留已有证据并标记“诊断未完成”，且不得生成或执行重试计划。

## Considered Options

- 允许 Agent 持续调用直到自行结束
- 只设置模型 API 超时
- 同时限制工具次数、工具重试和任务总时长（选择）

## Consequences

- 工作流需要在每个阶段检查剩余预算。
- 预算耗尽是可审计的任务终止原因。
- 评测应包含模型循环、工具循环、上下文膨胀和持续超时场景。
