# 限制公开演示环境的能力边界

公开演示环境不向匿名访客开放完整 Agent：匿名访客只能查看预置故障案例和已生成报告；登录后的交互演示只能从预置升级任务或故障案例发起诊断，不提供任意文本聊天入口。真实模型诊断受全站每天 20 次、每分钟 3 次的配额约束，真实重试执行关闭并使用模拟结果展示审批闭环；交互数据保留 24 小时后按确定性种子重建。这样在保留作品展示价值的同时，控制 API 费用、提示注入和公开写操作风险。

## Considered Options

- 匿名开放完整 Agent 和重试能力
- 完全不提供在线演示
- 匿名只读展示，受保护地开放模型调用并关闭真实写操作（选择）

## Consequences

- 演示环境需要区分预置报告、交互诊断和模拟执行。
- 模型接口必须具备身份验证、全站限流和每日配额，额度耗尽后降级为预生成报告而不是切换模型。
- 登录入口按来源 IP 临时限流，不采用会影响所有访客的共享账号全局锁定。
- 演示数据集需要支持整套重建，重建不修改存活数据集中的单条审计记录。
- 云端模型密钥只能通过平台 Secret 或环境变量注入，轮换后重启应用生效。
- README 和页面必须明确标识模拟数据与模拟执行。
