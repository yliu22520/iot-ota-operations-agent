# 分级展示决策轨迹但不展示原始思维链

系统不保存或展示模型的原始思维链，也不将其作为业务证据；系统保存可验证的决策轨迹，包括工具调用、证据引用、规则判断、阶段变化和简短理由。对外视图只展示结论与关键证据，运维视图展示完整决策轨迹，开发调试信息额外包含模型与 Prompt 版本、耗时、Token、异常和重试数据。

## Considered Options

- 按角色展示不同完整度的原始思维链
- 不保存任何解释过程
- 分级展示结构化决策轨迹，不展示原始思维链（选择）

## Consequences

- 运维人员可以验证结论依据，但不会把模型探索中的猜测误认为事实。
- 开发调试依赖结构化事件和技术遥测，而不是阅读模型内部推理文本。
- 前端和审计模型需要支持公开摘要、运维轨迹和开发遥测三种可见粒度。
- 运维详情按当前阶段、诊断报告、证据、重试计划、决策轨迹和审计时间线组织；开发遥测放入独立折叠面板，公开视图只保留报告摘要和关键证据。
- 当模型供应商要求在多轮工具调用中回传原始推理字段时，该字段只允许在单次模型交互的内存中短暂存在，交互结束后立即丢弃。
- 正式运行不保存完整 Prompt 或模型原始回复；本地评测可以保存脱敏后的 Prompt 与最终回复，用于分析回归差异。
