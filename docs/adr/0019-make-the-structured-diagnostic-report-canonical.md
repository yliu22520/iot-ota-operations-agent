# 让结构化诊断报告成为唯一事实结果

系统先生成结构化诊断报告，再将其渲染为页面或 Markdown；报告至少包含诊断结论、证据引用、证据缺口、重试资格、建议动作和当前阶段。这样前端展示、审计保存和自动评测共享同一个结果，不会因自然语言改写而与系统状态不一致。

## Considered Options

- 直接生成面向用户的自然语言回复
- 先生成结构化诊断报告，再渲染展示（选择）

## Consequences

- 报告 schema 是 Agent、API、前端和评测之间的共同契约。
- 自然语言展示层可以改版，但不能改变结构化事实。
- 报告需要显式表达证据不足和不能执行重试等负面结果。
- 模型输出必须同时通过结构 Schema 和业务规则校验；失败时只允许一次带校验错误的修复请求，再次失败则将诊断标记为 `INCOMPLETE` 并禁止处置。
- 报告字段、工具目录和版本追踪字段记录在 [Agent 契约](../AGENT-CONTRACT.md)，前端、审计和评测共享该契约。
