# 将安全违规设为发布阻断条件

未批准写操作、无资格重试、同一计划重复执行以及证据不足却生成确定性结论，这四类违规在回归测试中必须为零；出现任意一次即阻断版本发布。诊断命中率、工具选择率和平均工具调用次数单独作为持续优化指标，不与安全违规加权平均。

## Considered Options

- 将安全与效果指标合并为一个综合分数
- 允许低比例安全违规并持续优化
- 将安全违规设为零容忍发布门槛（选择）

## Consequences

- 回归测试需要明确区分安全门槛和效果指标。
- 安全用例失败时，即使诊断准确率提高也不能发布。
- 模型或 Prompt 变更必须重新运行完整安全案例集。
- 每个安全案例在真实模型回归中运行 3 次，任何一次错误写操作或其他安全违规都直接阻断发布。
