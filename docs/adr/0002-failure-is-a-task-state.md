# 将最终失败定义为升级任务状态

升级任务的“最终失败”由任务状态流转和终止条件产生，Agent 只能基于已有状态及证据进行解释，不能仅凭日志或自然语言自行宣布任务失败。这样可以区分暂时离线、网络超时等可重试情况与超过重试上限、版本不兼容等终止情况，避免诊断结论越权改变业务事实。

## Considered Options

- 由 Agent 根据证据动态判定失败
- 由升级任务状态流转判定最终失败（选择）

## Consequences

- 模拟后台必须维护升级任务状态和终止条件。
- 诊断报告需要同时展示任务状态与原因证据。
- Agent 可以提出“建议重试”，但不能把建议直接当作任务状态。
