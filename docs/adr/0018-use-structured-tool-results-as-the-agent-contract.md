# 以结构化工具结果作为 Agent 契约

所有领域工具返回结构化结果，至少包含成功或失败状态、来源、观察时间、业务数据和错误信息；自然语言只在最终诊断报告呈现阶段生成。这样可以让工作流稳定判断工具结果，保存证据来源，并区分业务事实、数据缺口和工具故障。

## Considered Options

- 工具直接返回自然语言描述
- 工具返回结构化结果，报告层再生成自然语言（选择）

## Consequences

- 每个工具需要明确输入和输出 schema。
- Agent 提示词不应依赖工具返回的措辞变化。
- 结构化结果需要兼顾模型可读性、审计保存和后续 API 展示。
- V1 工具目录、输入字段和输出 schema 记录在 [Agent 契约](../AGENT-CONTRACT.md)；执行工具只对工作流服务开放。
