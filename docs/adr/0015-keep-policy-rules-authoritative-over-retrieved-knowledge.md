# 让结构化规则优先于检索知识

版本兼容矩阵、重试次数和重试资格由结构化权威规则决定；运维手册和历史案例等检索知识只用于解释和补充诊断，不能覆盖实时规则、改变任务状态或授予重试权限。这样可以允许知识库持续扩展，同时避免过期文档或模型误读突破安全边界。

## Considered Options

- 让 Agent 综合所有上下文自行决定
- 让检索知识参与解释，但由结构化规则决定资格（选择）

## Consequences

- 规则与辅助知识需要有不同的数据模型和工具接口。
- 报告应区分“业务事实”和“参考说明”。
- 知识库更新不会直接改变重试权限，权限变化必须更新结构化规则。
- 日志、设备消息和检索文档均按不可信证据处理；其中出现的指令文本不能改变系统指令、工具权限或重试资格。
