# 在后端规则中强制校验重试资格

Agent 只能提出重试建议，重试资格必须由后端基于结构化业务条件确定，并在实际执行接口再次校验。最终失败、设备在线、版本兼容、失败类型可重试、未超过次数限制且仅影响单个任务等条件必须同时满足；模型的自然语言判断不能覆盖任何条件。

## Considered Options

- 由模型根据证据直接决定是否重试
- 由后端规则决定重试资格，Agent 只提出建议（选择）

## Consequences

- 需要把重试资格设计成可测试的结构化结果。
- 计划生成和执行接口都要校验，不能只在 UI 层拦截。
- 规则会限制部分看似合理的模型建议，但安全边界更清晰。
