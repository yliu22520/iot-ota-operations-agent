# 第一版使用可重复的模拟运维数据

第一版不连接公司系统、真实设备或跳板机，设备、升级任务、日志和故障状态全部由项目自建的模拟系统提供，并通过固定故障案例保持可重复。这样项目可以在家本地或云端独立运行，也能对工具选择、诊断原因和审批行为进行稳定回归；未来替换为真实 API 时，Agent 的领域接口仍可保持不变。

## Considered Options

- 连接公司或真实 IoT 环境
- 接入外部公开 IoT 平台
- 使用项目自建的可重复模拟数据（选择）

## Consequences

- 模拟系统必须明确记录每个故障案例的预期状态、证据和处置结果。
- 演示和评测不代表生产环境效果，简历与 README 必须如实说明这一点。
- 临时演示数据不做长期备份；数据库迁移、知识文档、故障案例和确定性种子进入版本库，保证环境可以重建。
- 领域工具接口需要与数据实现解耦，以便未来替换数据源。
